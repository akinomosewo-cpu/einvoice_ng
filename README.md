# E-Invoice NG

NRS-compliant e-invoicing for Nigerian SMEs. Creates validated invoices, tracks VAT, and manages buyer relationships.

## Setup
```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run
```

## Architecture
Clean Architecture + BLoC state management. Dark theme, advanced UI, Android & iOS.
